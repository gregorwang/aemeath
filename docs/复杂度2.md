# GIF 状态管理简化 — Codex 执行技术文档

## 背景

当前系统存在三套独立运行的状态系统（`StateMachine`、`BehaviorMode`、`GifStateMapper`），
它们通过信号松散耦合，导致一个简单操作（如点击"你在看什么"）会触发瀑布式连锁反应，
同时出现 4-5 个粒子 GIF窗口，视觉效果混乱。

### 核心问题
1. **音频检测的事件风暴**：TTS 自身播放也被 AudioDetector 当成外部音频，触发 MEDIA_PLAYING + 粒子效果
2. **粒子效果缺少场景抑制**：屏幕评论期间不应再产生大量粒子
3. **粒子数量和尺寸过大**：MAX_CONCURRENT=8 过多，scale 值过大
4. **FSM 状态转换连锁触发粒子**：HIDDEN→ENGAGED 时 `_on_state_changed_for_particles` 无条件触发 `on_engaged()` 生成粒子，即使是为了屏幕评论而 summon

替换为：

```python
    @Slot()
    def _on_audio_output_started(self) -> None:
        if not self._audio_output_reactive:
            return
        if self._self_playback_active:
            self.LOGGER.debug("[AudioOutputMonitor] 忽略本进程语音播放触发的音频输出")
            return
        # 屏幕评论会话期间，TTS fallback 产生的音频不应触发粒子和模式切换

        if self._gif_state_mapper and self._state_machine.current_state != EntityState.HIDDEN:
            self._gif_state_mapper.on_audio_started()
        self._set_behavior_mode(BehaviorMode.MEDIA_PLAYING)
```

## 修改 3：Director — FSM 状态变化时检查是否应跳过粒子

### 文件：`src/core/director.py`

### 变更 3.1：修改 `_on_state_changed_for_particles`

找到 `_on_state_changed_for_particles` 方法（约第 1611-1621 行）：

```python
    @Slot(object, object)
    def _on_state_changed_for_particles(self, old_state, new_state) -> None:
        """Forward state changes to GIF particle mapper."""
        if self._gif_state_mapper is None:
            return
        if new_state in (EntityState.PEEKING, EntityState.ENGAGED):
            self._gif_state_mapper.on_engaged()
        elif new_state == EntityState.FLEEING:
            self._gif_state_mapper.on_fleeing()
        elif new_state == EntityState.HIDDEN:
            self._gif_state_mapper.on_hidden()
```

替换为：

```python
    @Slot(object, object)
    def _on_state_changed_for_particles(self, old_state, new_state) -> None:
        """Forward state changes to GIF particle mapper."""
        if self._gif_state_mapper is None:
            return
        if new_state in (EntityState.PEEKING, EntityState.ENGAGED):
            # 屏幕评论触发的 summon 不需要生成兴奋粒子
            if not self._screen_commentary_session_active:
                self._gif_state_mapper.on_engaged()
        elif new_state == EntityState.FLEEING:
            self._gif_state_mapper.on_fleeing()
        elif new_state == EntityState.HIDDEN:
            self._gif_state_mapper.on_hidden()
```

## 验证清单

修改完成后，请按以下步骤验证：

1. **启动应用**，确认无导入/初始化错误
2. **点击托盘"你在看什么"**：
   - 应只看到主角色窗口，**不应出现多个大 GIF**
   - 如果 LLM 返回错误（401），fallback TTS 播放期间不应触发音乐律动粒子
3. **播放系统音乐**（非 TTS）：应看到最多 1 个小粒子飘入
4. **空闲唤醒**：角色从 HIDDEN→ENGAGED 时，最多出现 1 个小粒子
5. **所有现有测试通过**（如有）

## 注意事项

- **不要修改** `StateMachine`、`EntityWindow`、`TrajectoryPlayer` 这些类
- **不要修改** `BehaviorMode` 枚举的定义
- **不要修改** 粒子动画的 enter/exit/linger 生命周期逻辑
- **不要删除** 任何事件处理函数，只修改其内部逻辑
- 所有修改都是**向后兼容**的，不改变公共 API
