## 任务 1：GIF → Sprite Sheet 转换

### 目标

把项目中所有角色 GIF 转换为 Sprite Sheet（PNG + JSON 元数据），为后续的播放器集成做准备。

### 具体步骤

#### 1.1 创建转换脚本

- **文件位置**: `src/tools/gif_to_spritesheet.py`
- **参考**: `docs/动画png.MD` 第 13 章的完整代码
- **功能要求**:
  - 接受一个或多个 GIF 文件路径作为输入
  - 从 GIF 提取所有帧（正确处理增量帧和透明度）
  - 合并为一张横向排列的 PNG sprite sheet
  - 自动生成配套的 JSON 元数据文件
  - 支持 `--output-dir`、`--columns`、`--scale` 参数
- **依赖**: 只需要 `Pillow`（`pip install Pillow`）

#### 1.2 执行转换

运行脚本，将以下 GIF 文件全部转换：

```bash
python src/tools/gif_to_spritesheet.py characters/state1.gif characters/state2.gif characters/state3.gif characters/state4.gif characters/state5.gif characters/state6.gif characters/state7.gif characters/aemeath.gif --output-dir characters/sprites/
```

#### 1.3 验证输出

检查 `characters/sprites/` 目录下是否生成了以下文件：

```
characters/sprites/
  state1_sheet.png + state1_sheet.json
  state2_sheet.png + state2_sheet.json
  state3_sheet.png + state3_sheet.json
  state4_sheet.png + state4_sheet.json
  state5_sheet.png + state5_sheet.json
  state6_sheet.png + state6_sheet.json
  state7_sheet.png + state7_sheet.json
  aemeath_sheet.png + aemeath_sheet.json
```

每个 JSON 文件应包含 `frame_width`、`frame_height`、`frame_count`、`columns`、`default_fps` 等字段。

### 约束

- **不要修改任何现有代码文件**
- 只新增 `src/tools/gif_to_spritesheet.py` 和 `characters/sprites/` 下的文件
- 如果 `characters/` 下某个 GIF 不存在，跳过它，不要报错终止

## 任务 2：SpriteAnimator 播放器 + 系统集成

### 目标

创建一个基于 Sprite Sheet 的动画播放器类，并集成到现有的 `TrajectoryPlayer` 中，实现"优先 Sprite Sheet、fallback QMovie"的双模式加载。

### 具体步骤

#### 2.1 创建 SpriteAnimator 类

- **文件位置**: `src/ui/sprite_animator.py`
- **参考**: `docs/动画png.MD` 第 8 章的完整代码
- **核心能力**:
  - `load_from_files(sheet_path, meta_path)` — 加载 sprite sheet PNG + JSON 元数据
  - `play()` / `pause()` / `stop()` — 播放控制
  - `set_fps(fps)` — 运行时修改帧率
  - `set_frame(index)` — 跳转到指定帧
  - `set_flipped(bool)` — 水平翻转（左右镜像）
  - `set_scale(factor)` — 缩放
  - 预切所有帧到 `_frame_cache` 字典，避免播放时重复裁切
- **信号**:
  - `frame_changed(int)` — 帧索引变化
  - `animation_finished()` — 非循环动画播放完成
  - `loop_completed()` — 循环一圈完成

#### 2.2 修改 TrajectoryPlayer 支持双模式

- **修改文件**: `src/ui/gif_particle.py`
- **修改位置**: `TrajectoryPlayer._preload_movies()` 方法

**修改逻辑**:

```
对于每个 state_id 和对应的 gif_path:
  1. 构造 sprite sheet 路径: gif_path 所在目录 / "sprites" / "{stem}_sheet.png"
  2. 如果 sprite sheet 存在:
     → 创建 SpriteAnimator 实例
     → 调用 load_from_files() 加载
     → 存入 self._sprite_cache[state_id]
  3. 如果不存在:
     → 继续使用原来的 QMovie 逻辑
     → 存入 self._movie_cache[state_id]
```

**状态切换逻辑** (`_switch_to_state` 或类似方法):

```
当需要切换到某个 state_id 时:
  1. 先检查 self._sprite_cache 是否有该 state_id
  2. 如果有 → 隐藏当前 QMovie，显示 SpriteAnimator，调用 play()
  3. 如果没有 → 使用原来的 QMovie 逻辑（保持现有行为不变）
```

#### 2.3 增加方向翻转

在 `TrajectoryPlayer._on_timeline_value_changed()` 中，根据移动方向自动翻转动画：

```python
# 计算水平方向
dx = new_x - self._last_x  # 需要新增 self._last_x 记录
if dx < 0 and self._current_sprite:
    self._current_sprite.set_flipped(True)   # 向左
elif dx > 0 and self._current_sprite:
    self._current_sprite.set_flipped(False)  # 向右
```

#### 2.4 增加速度同步（可选）

如果时间允许，在 `TrajectoryPlayer` 中根据移动速度动态调整 SpriteAnimator 的帧率：

```python
speed = 距离 / dt  # 像素/秒
target_fps = max(5, min(30, speed / 10.0))
self._current_sprite.set_fps(target_fps)
```

### 约束

- **必须保留 QMovie 作为 fallback**。如果 Sprite Sheet 文件不存在，必须能正常使用 GIF
- 不要删除任何现有的 QMovie 相关代码
- 新增的 `_sprite_cache` 字典结构应与现有的 `_movie_cache` 平行
- `SpriteAnimator` 作为 `TrajectoryPlayer` 的子 widget 创建（`parent=self`）
- 注意：`TrajectoryPlayer` 在播放结束后会发出 `finished` 信号并自我销毁，`SpriteAnimator` 需要在这时正确清理

### 测试要点

- 删除 `characters/sprites/` 目录后，系统应该退回到使用 GIF，功能不受影响
- 有 Sprite Sheet 时，轨迹播放应使用 PNG 帧而不是 GIF
- 如果只有部分 state 有 Sprite Sheet（比如只转换了 state1 和 state2），其余 state 应 fallback 到 GIF

## 重要注意事项

1. **执行顺序**：必须先完成任务 1（生成素材），再做任务 2（集成到播放器）
2. **不要动 `docs/gif动画.md` 中描述的修复**：那些修复（轨迹平滑、触发链路、状态映射）应该已经由之前的 Codex 任务完成了。本次任务只做 Sprite Sheet 相关的工作
3. **现有的 `character_states.py` 可以复用**：在需要 state_id → gif_filename 映射时，从 `src/core/character_states.py` 导入 `CHARACTER_STATES`
4. **Pillow 可能已安装**：项目的 Python 环境中可能已有 Pillow。如果没有，只需 `pip install Pillow`
5. **文件编码**：所有 JSON 文件使用 UTF-8 编码，`ensure_ascii=False`
