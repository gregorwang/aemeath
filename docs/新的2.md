        """Locate the characters directory for GIF preview."""
        # Try common locations relative to the source tree
        candidates = [
            Path.cwd() / "characters",
            Path(__file__).resolve().parent.parent.parent / "characters",

        for candidate in candidates:
            if candidate.is_dir() and (candidate / "state1.gif").exists():

### 1.3 关键实现细节

1. **GIF 预览使用 `QMovie`**，设置 `setScaledSize(QSize(56, 56))` 避免图片过大。`QMovie.start()` 让缩略图循环播放动画。
2. **使用 `QScrollArea` 包裹**，因为内容较多可能超出窗口高度。
3. **`_find_characters_dir()` 是静态方法**，尝试从常见位置找到 `characters/` 文件夹。如果找不到，预览区不显示 GIF（仅显示灰色占位框）。
4. **不需要修改 `to_config()`**，因为这个 Tab 完全是只读预览，不产生任何配置数据。
5. **不需要修改 `_load_from_config()`** 和 `_restore_defaults()`，同理。
